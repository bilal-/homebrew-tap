# Homebrew tap

Homebrew formulas for tools by [bilal-](https://github.com/bilal-).

    brew install bilal-/tap/sous

| Formula | What it is |
|---|---|
| [sous](https://github.com/bilal-/sous) | One list of what is waiting on you, across every project |

The formulas are written by each project's release script. Please report
problems in the project's own repository.
